# Metric definitions

All timestamps remain original UTC strings; display may be UTC or browser local time. Nanosecond fractions are subtracted with BigInt before converting differences to milliseconds. Browser Date is used for human-readable date display only. `—` means unavailable, not zero. Source caveats live beside the affected panels.

| Metric                          | Source / unit                                                 | Population and time scope                                                  | Missing and aggregation rules                                                                                                                                             |
| ------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gateway requests                | `/metrics.gateway.total_requests`, count                      | Incoming handled inference requests, since restart                         | Never substituted with provider attempt count; absent is unavailable                                                                                                      |
| Active attempts                 | `/metrics.gateway.active_requests`, count                     | Sum of currently active provider counters                                  | Not gateway request concurrency or persistence backlog                                                                                                                    |
| Attempt errors and share        | `total_provider_errors / total_provider_attempts`             | Provider attempts, since restart                                           | Zero denominator → unavailable. Never divide by gateway requests                                                                                                          |
| Uptime                          | `/metrics.gateway.uptime_seconds`                             | Current process, seconds                                                   | Null/absent → unavailable                                                                                                                                                 |
| Provider health                 | `/providers.providers[].health,enabled`                       | Current registered instance                                                | Unknown is not healthy; disabled is a display state, not a control                                                                                                        |
| Session activity                | Difference of `total_requests`                                | Since dashboard mount, observed intervals, last 120 samples                | No rate normalization; first sample/reset/outage/pause gap → null. Counter or uptime decrease signals reset. Interval >12 s creates a gap. No synthetic historical points |
| Request latency                 | `total_latency_us / 1000`                                     | One recorded gateway request                                               | Null → unavailable; zero preserved. Not the sum of attempt durations                                                                                                      |
| Request TTFT                    | Earliest genuine first_token_at minus received_at             | One request, milliseconds                                                  | Exclude synthetic attempts and negative differences. First generation can be reasoning/tool output. No marker → unavailable                                               |
| Mean attempt TTFT               | Server comparison avg_ttft_ms                                 | All retained non-synthetic attempts with marker, including failed attempts | Server subtracts attempt timestamp. Sample count unavailable. Usage join can distort weighting                                                                            |
| Mean recorded duration          | Server comparison avg_duration_ms                             | Successful, non-synthetic attempts                                         | Backend streaming duration starts after dispatch returns. Never call it pure decode time, full end-to-end duration or gateway overhead                                    |
| Reported output throughput      | Server comparison avg_tokens_per_sec                          | Successful non-synthetic joined usage/attempt observations                 | completion_tokens * 1e6 / duration_us; zero duration excluded in SQL. Multiple updates affect weighting. Not pure decode speed or verified end-to-end output throughput   |
| Reported attempt volume/success | Server comparison total_attempts, successful_attempts         | All retained joined rows including synthetic timing                        | Displayed as reported with join caveat; not independently certified attempt counts. No weighted fleet average or percentile inferred                                      |
| Retry / switch                  | Adjacent ordered attempts                                     | One request                                                                | Same provider+model = retry; same provider different model = model switch; different provider = provider switch. No invented routing decisions                            |
| Request-relative event time     | Event timestamp minus received_at                             | One request                                                                | Preserve original timestamp. No attempt start inferred from duration. Synthetic events remain visible and labeled                                                         |
| Inter-chunk gap                 | Difference from prior contiguous sequence within same attempt | Genuine observed chunks only, ms                                           | No crossing attempt, sequence discontinuity or synthetic boundary. Negative differences unavailable. Chunk ≠ token; extracted bytes ≠ wire bytes                          |
| Timeline plot reduction         | Up to 250 time buckets per lane                               | Returned single-request events                                             | Keep largest gap in each bucket to preserve stall spikes. Exact rows paginated by 100, unchanged in explicit JSON export                                                  |
| Usage observations              | Detail usage rows                                             | Per attempt and returned observation                                       | Never sum updates without finality identity. Primary zero may mean unknown in current producer. Cached ⊂ prompt, reasoning ⊂ completion; invalid subsets flagged          |
| Usage row coverage              | Distinct attempt numbers with usage / recorded attempts       | One returned request                                                       | Coverage of rows, not certification of complete/final token measurement. No N+1 list enrichment                                                                           |
| Recovery sample                 | `/fallbacks`                                                  | Latest ≤200 non-success attempt rows on successful requests                | Distinct request IDs counted separately. Same-provider rows can be retries/model switches. No overall fallback-rate denominator                                           |
| Cost                            | No exposed read contract                                      | Unavailable                                                                | No inferred price/zero from provider name; configured zero and missing price remain distinct in future-contract fixtures                                                  |

Routine CSV export includes only the loaded request page, explicit server filters, mode, generation time, and original list fields. Formula prefixes are escaped. Comparison/reliability JSON exports label their returned scope. Prompt/response bodies appear only in explicit selected-request JSON export or copy; timeline export is separate. No export claims to contain all database history.
